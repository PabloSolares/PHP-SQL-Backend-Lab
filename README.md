# PHP & SQL Backend Lab

Colección de prácticas y proyectos de backend desarrollados con PHP, programación orientada a objetos, arquitectura MVC y bases de datos MySQL.

## Proyecto principal

La carpeta `proyecto-php-poo` contiene una aplicación web estructurada con el patrón MVC.

Incluye:

- Usuarios.
- Autenticación.
- Categorías.
- Productos.
- Carrito de compras.
- Órdenes.
- Modelos, controladores y vistas.
- Persistencia de información en MySQL.

También incluye el módulo `aprendiendo-php-mvc`, enfocado en la separación entre modelos, vistas y controladores.

## Tecnologías

- PHP
- Programación orientada a objetos
- Arquitectura MVC
- MySQL
- SQL
- HTML
- CSS
- JavaScript

## Conocimientos aplicados

- Diseño de bases de datos.
- Relaciones entre tablas.
- Consultas SQL.
- Operaciones CRUD.
- Autenticación.
- Separación de responsabilidades.
- Organización de proyectos backend.
- Integración entre PHP y MySQL.

## Instalación

Configura primero la conexión a la base de datos utilizando variables de entorno o un archivo local no versionado.

Después, ejecuta el proyecto mediante un servidor PHP local y configura la base de datos siguiendo los scripts SQL incluidos.
